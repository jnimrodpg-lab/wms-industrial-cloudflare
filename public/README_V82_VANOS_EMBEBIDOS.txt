V82 - Vanos embebidos y representación CAD mejorada

Cambios aplicados:
- La representación 2D de puertas, ventanas y vanos queda contenida dentro del espesor del muro.
- Se redujo la superposición visual del rótulo; ahora solo aparece cuando el vano está seleccionado.
- Se agregaron jambas internas y símbolo de puerta/ventana más limpio para lectura tipo CAD.
- En 3D se centraron mejor los elementos de ventana/puerta dentro del espesor del muro para evitar planos superpuestos extraños.
