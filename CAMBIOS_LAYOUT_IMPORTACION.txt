CAMBIOS APLICADOS

1) Vista Layout más estable
- Se redujo el temblor provocado por ResizeObserver + auto-fit mientras se arrastran zonas/racks.
- El layout ya no recalcula/re-renderiza todo el editor en cada movimiento del mouse; solo actualiza el SVG.
- Se evita actualizar el inspector lateral durante el arrastre para no cambiar medidas del escenario.

2) Importación de productos
- Se eliminó el límite local de 500 productos al guardar productos importados.
- Se subió el límite de lectura/importación desde Google Sheet de 12,000 a 50,000 filas.
- Se subió el límite guardado en Cloudflare/D1 para productos importados de 12,000 a 50,000.

3) Live Server
- Rutas CSS/JS en public/index.html corregidas a rutas relativas.
- Se agregó index.html en la raíz que redirige a public/index.html.

Nota: para importar muchas filas desde Google Sheets, la hoja debe estar accesible por enlace/permiso de lectura. En Live Server no existe backend de Cloudflare, por eso algunas funciones remotas solo estarán completas al desplegar en Cloudflare.
