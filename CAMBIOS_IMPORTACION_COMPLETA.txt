Corrección aplicada: importación completa en Live Server

Problema detectado:
- En modo Live Server no existe el backend /api/sheets/rows.
- El fallback local estaba leyendo Google Sheet vía GViz JSON y en algunos casos Google devuelve solo 500 filas.
- Por eso la búsqueda solo encontraba productos dentro de esos 500 registros cargados.

Cambios:
- Se cambió la lectura local de Google Sheet a GViz CSV con rango amplio A1:AZ50005.
- Se agregó parser CSV local para conservar todas las filas y columnas.
- Se mantiene fallback a GViz JSON con rango amplio si CSV falla.
- Límite local de importación: hasta 50,000 filas.
- Se actualizó también el default del backend a 50,000 filas.
- Se cambió el query string del script para evitar caché del navegador.

IMPORTANTE:
- Si ya tenías importados solo 500 registros, debes volver a importar la sucursal para reemplazar esa data antigua.
- En Vincular Sheet: seleccionar sucursal > Importar productos > Reemplazar.
- Después el contador debe subir por encima de 500 y la búsqueda trabajará sobre todos los productos cargados.
